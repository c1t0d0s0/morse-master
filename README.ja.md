## 🌟 概要

**モールスマスター (Morse Master)** は、PCのキーボード打鍵およびスマートフォンのタッチ操作の両方で快適に学習できるモダンなモールス信号トレーニングWebアプリケーションです。

**Web Audio API** によるクリックノイズのない美しい正弦波トーン再生、PARIS標準に基づく正確なWPM速度制御、そしてLEDインジケーターやオシロスコープ波形によるリアルタイム視覚フィードバックを備えています。

### ✨ 主な特長

- **🌐 ブラウザ言語の自動判定（i18n）**: 日本語版ブラウザでは日本語表示、それ以外の言語環境では英語表示を自動選択。ヘッダーのボタンからいつでもワンクリックで言語切替可能。
- **🎧 聞き取り練習モード**: 音声を聴いてタイピング回答。速度調節（5〜35 WPM）、ゆっくり再生（0.7倍）、音が出せない環境向けの消音・記号表示モード対応。
- **⚡ タップ送信練習モード**: 短点/長点を独立して打鍵する「**パドル**」と、押下時間で自動判定する「**電鍵（ストレートキー）**」の両方に対応。
- **📖 充実の符号一覧表**: アルファベット（A-Z）、数字（0-9）、和文モールス（カナ・濁点・半濁点・長音・句読点）、記号（?, !, /, @ 等）を網羅。各カードで音声を試聴可能。覚え方・語呂合わせ付き。
- **🔄 翻訳＆再生機**: 日本語（ひらがな・カタカナ）や英文・数字を即座にモールス信号に相互変換。ワンクリックで文字ごとのハイライト付き再生が可能。
- **📻 フリー電信機**: 好きなリズムで自由に打鍵すると、無音間隔を自動解析してリアルタイムにテキストへ解読。
- **📱 レスポンシブデザイン**: スマートフォン、タブレット、PCの画面サイズに最適化されたUI。

## 🚀 主な機能と練習モード

### 1. 🎧 聞き取り練習 (`ListeningQuiz`)
- **Web Audio API による高精度再生**: 650Hz（400〜1000Hzでカスタマイズ可能）のクリーンなモールス音を再生。
- **視覚・消音サポート**: 音を出せない場所でも、LEDランプの点滅やオシロスコープ波形、および「・－」記号表示で練習可能。
- **3段階の難易度設定**:
  - **初級**: 1文字・基礎符号
  - **中級**: 2〜4文字の頻出単語、略符号（CQ、SOS、73 等）、数字
  - **上級**: 5文字以上の英単語、長文、濁点・半濁点付き和文
- **フィードバックと覚え方解説**: 正誤判定、連続正解ストリーク（3連勝ごとに紙吹雪演出）、回答後の文字分解と語呂合わせ・フォネティックコード解説。

### 2. ⚡ タップ送信練習 (`TappingQuiz`)
- **パドルモード**: 短点（`・`）と長点（`－`）の2つのボタンで入力。
- **電鍵モード**: 実物の電信機のように、タップ・長押しした時間から短点・長点を自動判定。
- **PCキーボードショートカット**:
  - `J` または `F`: 短点 (`.`)
  - `K` または `D`: 長点 (`-`)
  - `Space`: 次の文字へ確定 / 電鍵押下
  - `Enter`: 判定する
  - `Backspace`: 直前の入力を1文字削除

### 3. 📖 符号一覧表 (`ReferenceChart`)
- カテゴリ別タブ: **アルファベット**、**数字**、**和文モールス**、**記号**、**すべて表示**。
- 文字・読み・符号・覚え方でのリアルタイム検索フィルター。
- 各カードをクリックして音声を試聴。

### 4. 🔄 翻訳＆再生 (`Translator`)
- 自然文（日本語カナ・英語・数字）とモールス信号の相互変換。
- 和文濁点・半濁点の自動分解・結合処理。
- 文字単位のアニメーションハイライト付き再生・停止。
- 定番プリセット（`SOS`, `CQ`, `73`, `こんにちは`, `本日晴天ナリ` 等）。
- 記号（`・－`）または Raw（`.-`）形式でのクリップボードコピー。

### 5. 📻 フリー電信機 (`FreeKeyer`)
- 手動打鍵のリズムから文字の区切りを自動検知してテキストに解読。
- 打鍵した符号履歴の表示とテキストのワンクリックコピー。

## 📦 インストールと起動方法

### 前提条件

- [Node.js](https://nodejs.org/) (バージョン 18 以上推奨)
- `npm` または `pnpm` / `yarn`

### 手順

1. リポジトリをクローンまたはダウンロード:
   ```bash
   git clone <repository-url>
   cd morse-master
   ```

2. 依存パッケージをインストール:
   ```bash
   npm install
   ```

3. 開発サーバーを起動:
   ```bash
   npm run dev
   ```
   ブラウザで `http://localhost:5173` にアクセスします。

## 🌐 多言語対応（i18n）について

ブラウザの言語設定に応じた自動判別を行います。
- **日本語環境** (`ja`, `ja-JP` 等) のブラウザでアクセスした場合は **日本語** で表示されます。
- **それ以外の言語環境** (`en`, `fr`, `de`, `zh`, `es` 等) では **英語** で表示されます。
- ヘッダー右上の地球アイコンボタン、または設定モーダルから手動でいつでも切り替えることができます。
